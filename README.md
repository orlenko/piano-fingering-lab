# piano-fingering-lab

Local-first experiments extracting observed piano fingerings and synchronizing performance video with sheet music.

Clone the experiment:

```sh
git clone https://github.com/orlenko/piano-fingering-lab.git
cd piano-fingering-lab
```

Read `HANDOFF.md` for the first implementation task and `AGENTS.md` for experiment rules. On the operator's prepared checkout, private input locations are in `.local/inputs.json`.

Implementation has not started. There is no processing or test command yet; model dependencies and executable setup will be documented when the prototype is built. Do not commit recordings, purchased scores, checkpoints, or generated media.
